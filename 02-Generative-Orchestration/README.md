# Lab 02 — Generative Orchestration

## Objective

Demonstrate and document Copilot Studio generative orchestration and how an agent can dynamically use available knowledge, topics, and tools to determine how to respond to a user request.

## Configuration Observed

The IT Support Conversation Agent is configured with:

- Generative AI orchestration: Enabled
- Connected agents: Enabled
- Knowledge sources available to the agent
- Tools available to the agent

## Lab Focus

This lab focuses on understanding how generative orchestration can coordinate agent capabilities rather than relying exclusively on manually defined conversation paths.

## AB-620 Practice Focus

This lab reinforces the AB-620 skill area:

**Integrate and extend agents in Copilot Studio**

The configuration demonstrates the relationship between:

- Generative orchestration
- Knowledge
- Topics
- Tools
- Connected agents
